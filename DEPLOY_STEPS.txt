================================================================================
        RAILWAY DEPLOYMENT - STEP BY STEP GUIDE
        DeaSirnicko Laravel Application
================================================================================

TOTAL TIME: 10-15 MINUTES
DATABASE: MySQL (Your Current Setup)

================================================================================
PART 1: PREPARATION (5 MINUTES)
================================================================================

STEP 1: Generate APP_KEY
------------------------
Open Command Prompt or PowerShell in your project folder:

    cd c:\laragon\www\Dea'sproject\DeaSirnicko
    php artisan key:generate --show

COPY THE OUTPUT! You'll need it later.
Example output: base64:abcdefghijklmnopqrstuvwxyz1234567890ABCD==

SAVE IT HERE: _________________________________


STEP 2: Install Dependencies (if not done)
-----------------------------------------
    composer install
    npm install


STEP 3: Build Assets
-------------------
    npm run build

Wait for it to complete. Should see "built in XXms" message.


STEP 4: Initialize Git (if not done)
-----------------------------------
    git init
    git add .
    git commit -m "Ready for Railway deployment"


STEP 5: Create GitHub Repository
-------------------------------
1. Go to: https://github.com/new
2. Repository name: deasirnicko (or your choice)
3. Keep it Public or Private (your choice)
4. DON'T check "Initialize with README"
5. Click "Create repository"

COPY YOUR REPO URL: _________________________________
Example: https://github.com/YOUR_USERNAME/deasirnicko.git


STEP 6: Push to GitHub
---------------------
Replace YOUR_GITHUB_URL with your actual URL from Step 5:

    git remote add origin YOUR_GITHUB_URL
    git branch -M main
    git push -u origin main

Enter your GitHub username and password/token when prompted.

================================================================================
PART 2: RAILWAY SETUP (5 MINUTES)
================================================================================

STEP 7: Create Railway Account
-----------------------------
1. Go to: https://railway.app
2. Click "Login" (top right)
3. Choose "Login with GitHub" (easiest)
4. Authorize Railway to access GitHub
5. You'll see Railway Dashboard


STEP 8: Create New Project
-------------------------
1. Click "New Project" (big button)
2. Select "Deploy from GitHub repo"
3. Choose your repository: deasirnicko
4. Railway starts building automatically
5. Wait 3-5 minutes for first build


STEP 9: Add MySQL Database
-------------------------
1. In your project dashboard, click "+ New" button
2. Select "Database"
3. Choose "MySQL"
4. Wait 30 seconds for provisioning
5. MySQL service appears in your project

YOUR MYSQL IS NOW READY!


STEP 10: Configure Environment Variables
---------------------------------------
1. Click on your APPLICATION service (not MySQL)
2. Click "Variables" tab
3. Click "+ New Variable" button

ADD THESE VARIABLES ONE BY ONE:

Variable 1:
    Name: APP_KEY
    Value: [Paste the key from STEP 1]

Variable 2:
    Name: APP_ENV
    Value: production

Variable 3:
    Name: APP_DEBUG
    Value: false

Variable 4:
    Name: DB_CONNECTION
    Value: mysql

4. Click outside or press Enter to save each one
5. Railway will restart your service automatically

================================================================================
PART 3: DEPLOYMENT (3 MINUTES)
================================================================================

STEP 11: Install Railway CLI
---------------------------
Open PowerShell as Administrator:

    npm install -g @railway/cli

Wait for installation to complete.


STEP 12: Login to Railway
------------------------
    railway login

This opens your browser. Click "Confirm" to authenticate.


STEP 13: Link Your Project
-------------------------
    cd c:\laragon\www\Dea'sproject\DeaSirnicko
    railway link

Choose your project from the list using arrow keys, press Enter.


STEP 14: Run Database Migrations
-------------------------------
    railway run php artisan migrate --force

Type "yes" when prompted.
Wait for migrations to complete.


STEP 15: (Optional) Seed Initial Data
------------------------------------
If you have seeders:

    railway run php artisan db:seed --force

================================================================================
PART 4: VERIFICATION (2 MINUTES)
================================================================================

STEP 16: Get Your App URL
------------------------
1. Go to Railway Dashboard
2. Click on your application service
3. Click "Settings" tab
4. Scroll to "Domains" section
5. You'll see: your-app-name.up.railway.app

COPY YOUR URL: _________________________________


STEP 17: Test Your App
---------------------
Open browser and visit:

    https://your-app-name.up.railway.app

You should see your Laravel welcome page!


STEP 18: Test Health Check
-------------------------
Visit:

    https://your-app-name.up.railway.app/up

Should display: OK


STEP 19: Test Registration
-------------------------
1. Go to: https://your-app-name.up.railway.app/register
2. Create a test account
3. Try logging in
4. Verify everything works


STEP 20: Check Logs (If Issues)
------------------------------
If something doesn't work:

    railway logs --follow

Press Ctrl+C to stop viewing logs.

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM 1: "Vite manifest not found"
-----------------------------------
SOLUTION:
    1. Run locally: npm run build
    2. Commit: git add . && git commit -m "Fix build"
    3. Push: git push


PROBLEM 2: "500 Internal Server Error"
-------------------------------------
SOLUTION:
    railway run php artisan config:clear
    railway run php artisan config:cache
    railway logs


PROBLEM 3: "Database connection failed"
--------------------------------------
SOLUTION:
    1. Check DB_CONNECTION=mysql is set in Railway variables
    2. Check MySQL service is running (green in dashboard)
    3. railway run php artisan tinker
    4. Run: DB::connection()->getPdo();


PROBLEM 4: "APP_KEY not set"
---------------------------
SOLUTION:
    1. Generate: php artisan key:generate --show
    2. Copy the output
    3. Add to Railway variables: APP_KEY = [paste]


PROBLEM 5: Changes not showing
-----------------------------
SOLUTION:
    1. Make changes locally
    2. git add .
    3. git commit -m "Update"
    4. git push
    5. Railway auto-deploys
