## 🚀 Railway MySQL Setup

### Step 1: Add MySQL Database

In your Railway project:
1. Click **"+ New"**
2. Select **"Database"**
3. Choose **"MySQL"**
4. Wait ~30 seconds for provisioning

### Step 2: Verify Auto-Generated Variables

Railway automatically creates these variables:

| Railway Variable | Laravel Uses As |
|------------------|-----------------|
| `MYSQLHOST` | `DB_HOST` |
| `MYSQLPORT` | `DB_PORT` |
| `MYSQLDATABASE` | `DB_DATABASE` |
| `MYSQLUSER` | `DB_USERNAME` |
| `MYSQLPASSWORD` | `DB_PASSWORD` |

**You don't need to manually set these!** Railway connects them automatically.

### Step 3: Set DB_CONNECTION

In your app service → Variables:
```
Variable: DB_CONNECTION
Value: mysql
```

This tells Laravel to use MySQL driver.

## 🚨 Common MySQL Issues

### Issue 1: "SQLSTATE[HY000] [2002] Connection refused"

**Solution:**
```bash
# Check DB_CONNECTION is set
railway variables get DB_CONNECTION
# Should return: mysql

# Verify MySQL service is running
railway status
# MySQL should show as "Active"
```

---

### Issue 2: "Access denied for user"

**Solution:**
```bash
# Check if MySQL variables exist
railway variables | grep MYSQL

# Should see:
# MYSQLHOST=...
# MYSQLPORT=3306
# MYSQLDATABASE=...
# MYSQLUSER=...
# MYSQLPASSWORD=...
```

If missing, the MySQL service isn't connected properly. Remove and re-add it.

---

### Issue 3: "Database doesn't exist"

**Solution:**
Railway auto-creates the database. If you see this error:

```bash
# The database name in Railway might be different
railway variables get MYSQLDATABASE
# Use this exact name in your migrations
```

---

### Issue 4: Migrations fail with "Syntax error"

**Solution:**
```bash
# Check MySQL version compatibility
railway run mysql --version

# Should be MySQL 8.0+
# All Laravel 12 migrations are compatible
```

## 📊 Monitoring MySQL

### Check Database Size

```bash
railway run mysql -u $MYSQLUSER -p$MYSQLPASSWORD -e "
SELECT 
    table_schema AS 'Database',
    ROUND(SUM(data_length + index_length) / 1024 / 1024, 2) AS 'Size (MB)'
FROM information_schema.tables
WHERE table_schema = '$MYSQLDATABASE'
GROUP BY table_schema;
"
```

### Check Table Sizes

```bash
railway run php artisan tinker
# Run:
DB::select("
    SELECT 
        table_name AS 'Table',
        ROUND(((data_length + index_length) / 1024 / 1024), 2) AS 'Size (MB)'
    FROM information_schema.TABLES
    WHERE table_schema = DATABASE()
    ORDER BY (data_length + index_length) DESC;
");
```
