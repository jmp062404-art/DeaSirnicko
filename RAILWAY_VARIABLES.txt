================================================================================
HOW TO ADD EACH VARIABLE IN RAILWAY:
================================================================================

For each variable above:

1. Click "+ New Variable" button in Railway

2. In the "Name" field, paste the variable name
   Example: APP_KEY

3. In the "Value" field, paste the variable value
   Example: base64:3uZZl5P/ExhbpSRmz92e7RnPuB1Ww3QsAYKUOTtc2ME=

4. Press Enter or click outside to save

5. Repeat for the next variable

================================================================================
IMPORTANT NOTES:
================================================================================

1. NEVER commit .env file to GitHub (it's already in .gitignore)

2. APP_KEY is unique - the one above is generated specifically for your app

3. Keep APP_DEBUG=false in production (security!)

4. DB_CONNECTION must be "mysql" (not "pgsql")

5. MySQL connection variables are auto-created by Railway - don't add manually

6. After adding variables, Railway will automatically restart your service

================================================================================
WHAT TO DO AFTER ADDING VARIABLES:
================================================================================

1. Wait 1-2 minutes for Railway to restart your service

2. Check deployment logs in Railway dashboard

3. Run migrations:
   railway run php artisan migrate --force

4. Seed database:
   railway run php artisan db:seed --force

5. Test your app at the Railway URL!

================================================================================
TROUBLESHOOTING:
================================================================================

Problem: "The only supported ciphers are AES-128-CBC and AES-256-CBC"
Solution: Make sure APP_KEY starts with "base64:" and is exactly as shown above

Problem: "Database connection failed"
Solution: 
  1. Check DB_CONNECTION=mysql is set
  2. Check MySQL service is running in Railway
  3. MySQL variables should be auto-generated

Problem: "APP_KEY not set"
Solution: Double-check you added the APP_KEY variable with the exact value above
